# コーポレートサイトのトップビュー定番パターン

コーポレートのトップビューは、CV を急がせる LP の FV とは狙いが違う。第一印象で信頼と事業領域を伝え、各オーディエンスを正しい入り口へ導くことが役割になる。以下は企業像に応じて選ぶ型。

## 1. フルスクリーン・キービジュアル＋短いブランドステートメント

画面いっぱいの写真や映像に、短く力のあるブランドステートメント（理念やパーパス）を重ねる。ブランドの世界観や規模感で信頼を作りたい大企業・ブランド志向の企業に向く。具体的な事業説明は下層に譲り、トップは印象に集中する。

## 2. 事業領域を即時に示すグリッド

トップに事業やサービスのカードをグリッドで並べ、「何をやっている会社か」を一目で示す。複数事業を持つ企業や、まず事業内容を伝えたい BtoB 企業に向く。求職者・取引先がすぐ目的地を見つけられる。

## 3. 動画背景＋コピー

背景にループ動画を敷き、中央にコーポレートメッセージを置く。ものづくり、技術、現場の躍動を見せたい製造業・インフラ・スタートアップに向く。動画の容量と、再生できない環境でのフォールバックに注意する。

## 4. 最新情報 / 実績を前面に出す型

トップの目立つ位置にニュース、プレスリリース、実績数値を配置し、「今動いている企業」という鮮度を伝える。IR を重視する上場企業や、活動量で信頼を示したい企業に向く。更新が止まると逆効果なので、運用体制とセットで選ぶ。
